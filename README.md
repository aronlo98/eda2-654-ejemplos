Este repositorio esta pensado como un espacio de documentacion y apoyo para la clase de **Estructuras de Datos 2**. Aqui iremos organizando los temas por carpetas, de modo que el `README.md` principal funcione como una portada sencilla del curso.

- [Arboles Rojos-Negros](./arboles-rojos-negros/README.md)
- [Grafos](./grafos/README.md)
- [Grafos Bipartitos](./grafos-bipartitos/README.md)
- [Recorridos en Grafos](./recorridos-grafos/README.md)
- [Árboles de Expansión Mínima](./arboles-expansion-minima/README.md)

## Objetivo

La idea es que cada tema tenga su propio material explicativo, ejemplos y ejercicios, para que los alumnos puedan revisar cada estructura de datos de forma independiente y ordenada.
